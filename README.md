To-Do List Web App

A simple and stylish to-do list web application built with HTML, CSS, and JavaScript. Users can add tasks, mark them as completed, and remove them.

Features

Add new tasks dynamically

Visual indication of task completion (line-through)

Remove tasks easily

Responsive and clean UI


Technologies Used

HTML

CSS

JavaScript


Screenshots



How to Run

1. Clone or download this repository.


2. Make sure the following files are in the same directory:

index.html

style.css

script.js

book.jpg (icon image)



3. Open index.html in any web browser.



Project Structure

├── index.html       # HTML structure
├── style.css        # Stylesheet for the app
├── script.js        # Script handling task logic
└── book.jpg         # Image used in header

Notes

A pop-up alert appears when the app loads ("Hii").

Tasks can be added using the input field and "ADD" button.

Click on a task to mark it as completed.

Click the "×" icon to remove a task (removal logic can be added).
